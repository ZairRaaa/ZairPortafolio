03 / TRABAJO 2 · LABORATORIO

Apex Motors:
explorar con intención.

Un catálogo de vehículos deportivos sirve como escenario visual para la primera práctica de hooks: entender el renderizado, trabajar efectos y separar lógica reutilizable.

EXPLORAR EL CÓDIGOSemana_7_practica_1↗

Efectos con un ciclo claro

La guía propone async/await dentro de useEffect, dependencias explícitas y AbortController para cancelar peticiones durante la limpieza.

Compartir y reutilizar

El ejercicio conecta useContext para el tema, useRef para el foco y un hook personalizado para encapsular lógica. useMemo y useCallback se estudian junto al Profiler.

¿Qué observar durante el renderizado? +

Una actualización de estado puede volver a renderizar el componente. La práctica invita a revisar qué cambió con React DevTools y a comprobar las dependencias de los efectos. En desarrollo, StrictMode puede repetir un ciclo de preparación y limpieza para detectar problemas.

Las evidencias muestran la portada y el catálogo. La cancelación de peticiones y las mejoras de rendimiento se comprueban en el código y con mediciones, no solo con la apariencia de la página.

05 / MAPA DE HOOKS

Una necesidad.
Una herramienta.

Abre cada tarjeta para repasar qué responsabilidad cumple cada hook en los trabajos de esta semana.

useState · Interfaz local

Mantiene valores que afectan a la interfaz, como un campo de formulario o un control abierto.

useReducer · Transiciones

Organiza acciones sobre un estado complejo en una función reducer, conservando actualizaciones inmutables.

useEffect · Sincronización

Conecta el componente con sistemas externos. La limpieza libera listeners o cancela operaciones cuando corresponde.

useContext · Datos compartidos

Permite consumir el tema desde un proveedor sin pasar esa información manualmente por cada nivel.

useMemo · Cálculos derivados

Puede reutilizar un cálculo de filtrado u ordenación mientras no cambien sus dependencias. Se aplica cuando aporta una mejora medible.

useCallback · Referencias estables

Puede mantener la identidad de un handler entre renders, por ejemplo al enviarlo a un hijo memoizado.

useRef · Referencias persistentes

Conserva una referencia al input para darle foco. Cambiar ref.current no provoca un render.

Hook personalizado · Reutilización

useLocalStorage encapsula lectura, escritura y sincronización. Un hook comparte lógica, no convierte automáticamente su estado en global.

06 / LO QUE APRENDÍ

El cambio tiene
su propia lógica.

Separar responsabilidades

La interfaz, las transiciones de estado y la persistencia resuelven problemas distintos. Organizar cada responsabilidad hace más fácil entender qué ocurre cuando el usuario interactúa.

Evitar datos duplicados

Una lista filtrada o una métrica se puede obtener del estado original. Mantener una sola fuente de datos reduce la necesidad de sincronizar valores manualmente.

Medir con una pregunta concreta

Antes de añadir memoización, conviene identificar qué componente se renderiza, por qué y cuánto cuesta. La optimización tiene sentido cuando responde a un problema observado.
