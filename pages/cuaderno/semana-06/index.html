03 / TRABAJO 2

Nido: cada ruta
abre una posibilidad.

Una propuesta de catálogo que organiza la experiencia en tres vistas: descubrir, explorar productos y realizar una consulta.

EXPLORAR EL CÓDIGOSemana_6_practica_2↗

Navegar entre vistas

Las capturas muestran Inicio, Catálogo y Consultas. La guía plantea routing del lado del cliente con React Router, además de una página para rutas no encontradas.

Dar forma a los datos

El catálogo muestra productos, precios, búsqueda y categoría. La guía conecta esta vista con Axios, async/await y estados de carga, datos y error.

Eventos, listas y formularios +

El trabajo propone listas con claves estables, renderizado condicional y un formulario controlado. Cada cambio de campo actualiza el estado; la interfaz debe informar cuándo carga o cuándo falla una petición.

Las imágenes documentan las vistas disponibles. La cancelación de peticiones, los estados de error y la navegación sin recarga requieren comprobar el proyecto en ejecución.

04 / TRABAJO 3 · RECUPERACIÓN

TecnoAndes: componer
para comprender.

El panel de ventas reúne métricas, gráficos, pedidos y un laboratorio de estilos. Recuperación de la práctica de la semana 5, documentada en esta semana.

EXPLORAR EL CÓDIGOZAIR-ROJAS-SEMANA_05↗

Props y composición

El informe describe App como organizador y Dashboard como estructura compartida. Panel y MetricCard reciben datos mediante props y contenido mediante children.

Tres formas de aplicar estilos

CSS Modules organiza los estilos por componente; Tailwind aporta utilidades; los estilos inline permiten expresar valores dinámicos. La captura de StyleLab compara las tres estrategias.

Del HTML inicial al DOM de React +

El documento describe un inspector de CSR que compara el HTML inicial con el DOM después del montaje. Su objetivo es observar cómo React incorpora la interfaz en el navegador.

Las evidencias incluidas muestran el panel, su vista móvil y el laboratorio de estilos. No incluyen una captura del inspector ni nuevas mediciones de rendimiento.

05 / LO QUE APRENDÍ

Construir también es
conectar ideas.

¿Qué conecta los trabajos?

Separar responsabilidades: los componentes organizan la interfaz, las props transportan información y las rutas ordenan la experiencia.

¿Cómo se complementan?

Órbita hace visible el recorrido de un objeto. Nido lleva el trabajo hacia páginas y datos. TecnoAndes reúne composición y estilos dentro de un panel.

¿Qué seguir revisando?

La adaptación a distintas pantallas, los estados de carga y error, la claridad del formulario y la separación entre datos, presentación y comportamiento.
