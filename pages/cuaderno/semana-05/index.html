¿Qué significa Client Side Rendering? +

En CSR, el navegador ejecuta JavaScript para construir la interfaz. Una plantilla habitual de React con Vite carga un documento HTML y monta los componentes en un elemento raíz.

Next.js no se limita a CSR: puede entregar HTML generado previamente o en el servidor y añadir interacción en el cliente. Un Client Component también puede participar en el HTML inicial generado en el servidor.

03 / RECONOCER EL PROYECTO

Las carpetas también
cuentan una historia.

Estas estructuras ilustran dos formas de organizar una aplicación React. Los nombres pueden variar según la plantilla y las opciones elegidas.

React con Vite

mi-proyecto/
├── index.html       # Documento de entrada
├── package.json     # Dependencias y scripts
├── public/          # Recursos públicos
└── src/
    ├── main.jsx     # Montaje de React
    ├── App.jsx      # Componente principal
    └── index.css    # Estilos

Next.js · App Router

mi-proyecto/
├── package.json     # Dependencias y scripts
├── public/          # Recursos públicos
└── app/             # Puede estar en src/app
    ├── layout.tsx   # Estructura compartida
    ├── page.tsx     # Página de inicio
    └── globals.css  # Estilos globales

¿Dónde se gestionan las dependencias?

package.json declara paquetes y scripts. El archivo de bloqueo, como package-lock.json con npm, registra versiones resueltas; node_modules contiene los paquetes instalados y normalmente se excluye de Git.

El comando para iniciar el proyecto depende de sus scripts. Conviene leer package.json antes de asumir cómo ejecutarlo.
